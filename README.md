#  Retro-Modern Interactive Portfolio

An interactive, dual-themed personal portfolio website engineered to showcase a diverse range of work spanning frontend development, embedded hardware, and high-retention video editing. 

The application detects the user's viewport and dynamically serves one of two distinct operating system experiences: a nostalgic, fully interactive **Windows 95 desktop** for large screens, or a sleek, gesture-driven **iOS-style interface** for mobile devices.

##  Key Features

* **Dual-OS Architecture:** Seamlessly switches between a React95-powered desktop environment and a custom-built iOS mobile shell based on device width.
* **Authentic Boot Sequences:** Features a custom BIOS memory check, a classic Windows 95 boot screen, and an authentic shutdown sequence.
* **Interactive Desktop:** Fully draggable windows, functional minimize/close states, dynamic z-indexing, and a working Start Menu.
* **Mobile App Shell:** iOS-inspired bottom sheet for project previews, an animated app dock, and a simulated mobile launch screen.
* **Integrated Media Viewer:** Custom video players and file explorers designed to display retention-based storytelling edits, visual effects, and web/hardware project demos.

##  Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** React 
* **Language:** TypeScript
* **Styling:** Tailwind CSS & [Styled-Components](https://styled-components.com/)
* **UI Components:** [React95](https://github.com/React95/React95) (Win95 design system)
* **Deployment:** Vercel

##  Showcased Domains

This portfolio is structured to house projects across three primary disciplines:

1. **Frontend Development:** Web applications utilizing React.js, Node.js, Tailwind CSS, and Shopify Liquid (e.g., *P3KCARS*).
2. **Hardware & Embedded IoT:** Microcontroller and communication projects using ESP32, ESP8266, and LoRa technology (e.g., *HikeSafe* emergency system, *8-Bit Program Counter*).
3. **Video Production:** High-retention edits, documentary-style storytelling, and 3D camera tracking utilizing DaVinci Resolve and Fusion.
